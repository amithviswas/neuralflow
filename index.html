Agents that work together

Define agents with a model and tools, then chain or branch them into a flow that plans, acts and answers.

  • Planner, worker and reviewer patterns
  • Typed tools from plain Python functions
  • Retries, timeouts and hand-offs per step
orchestration.py
from neuralflow import Flow, Agent, tool

@tool
def search_docs(query: str) -> list[str]:
    return index.search(query, k=5)

planner = Agent("planner", model="any-llm", tools=[search_docs])
writer = Agent("writer", model="any-llm")

flow = Flow("answer-question")
flow.chain(planner, writer)

result = flow.run("How do refunds work?")
print(result.output)

Pipelines for real data

Compose load, prompt, validate and save steps into a pipeline that runs in batches and picks up where it failed.

  • Batching and concurrency controls
  • Schema validation on every LLM output
  • Automatic retries and resumable runs
pipeline.py
from neuralflow import Pipeline, steps

pipe = (
    Pipeline("enrich-leads")
    .add(steps.Load("leads.csv"))
    .add(steps.LLM("Summarise each company", model="any-llm"))
    .add(steps.Validate(schema=LeadSummary))
    .add(steps.Save("warehouse.leads"))
)

pipe.run(batch_size=32, retries=2)

See every step

Every run produces a trace: which agent did what, which tools it called, how long it took and what it cost.

  • Step-level traces with latency and tokens
  • Export to console, files or your own stack
  • Replay a run to debug it
observe.py
from neuralflow import Flow
from neuralflow.observe import Tracer

flow = Flow.load("answer-question")
tracer = Tracer(export="console")

with tracer.session("debug-run"):
    run = flow.run("Draft a reply to ticket #4821")

for span in run.trace:
    print(span.step, span.latency_ms, span.tokens)

Extend anything

Plugins hook into the flow lifecycle, so you can add tools, providers, storage or alerts without forking.

  • Lifecycle hooks for steps and runs
  • Bring your own model provider
  • Share plugins as regular packages
plugin.py
from neuralflow import Flow
from neuralflow.plugins import Plugin, register

@register
class SlackNotify(Plugin):
    name = "slack-notify"

    def on_step_end(self, step, result):
        self.post(f"{step.name} finished in {result.ms} ms")

flow = Flow.load("enrich-leads", plugins=["slack-notify"])

How it works

From idea to running flow in three steps.

  1. 01

    Define your agents and tools

    Pick a model, describe the role, hand it plain Python functions as tools.

  2. 02

    Connect them into a flow

    Chain, branch or loop agents and pipeline steps into one graph.

  3. 03

    Run, monitor and iterate

    Run locally or at scale, read the trace, then tune prompts and steps.
